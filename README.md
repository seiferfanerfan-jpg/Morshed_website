# SEIFAi — مرشد AI

واجهة عربية متجاوبة لتجربة راشد، مساعد المحادثة والنموذج الفرعي من مرشد AI ضمن تطبيق مرشد _ S7. مبنية بـReact وTypeScript وVite.

## التشغيل المحلي

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج والتحقق من الأنواع:

```bash
npm run build
```

## هوية وتجربة المساعد

- اسم التطبيق: **SEIFAi**.
- المساعد الحواري: **راشد**، نموذج فرعي من **مرشد AI** ضمن تطبيق **مرشد _ S7**.
- مرشد AI داخل التطبيق مخصص للتنبيهات والتذكيرات والتكامل معه؛ راشد مخصص للتجربة الحوارية.
- الإجابات قد تحتوي على أخطاء؛ ينبغي مراجعة المعلومات المهمة.
- تسجيل المحاضرات وتدوينها وتلخيصها، ودعم الصور والملفات والتسجيلات الصوتية، مزايا قادمة وليست متاحة حاليًا.
- قسم الصور ونسخ صور الهاتف ضمن تصور التطبيق، لكن لا يُقدَّم كميزة متاحة قبل تنفيذها، ولا تُضمن مساحة تخزين غير محدودة.
- يعرّف المساعد منشأ التطبيق بأنه من تطوير فريق مرشد AI بقيادة سيف عرفان، وأن فكرته صُنعت بمحبة بين سيف وحبيبته.

## النشر على Cloudflare Pages

الموقع المنشور: https://morshed-ai-8vu.pages.dev/

أنشئ المشروع كرفع مباشر باستخدام Wrangler. لإعادة النشر بعد تعديل الموقع، اضبط `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID` في بيئتك دون حفظهما في Git، ثم شغّل:

```bash
npm run build
npx wrangler pages deploy dist --project-name=morshed-ai --branch=main
```

مشروع Pages الحالي رُفع مباشرة، ولا يزامن النشر تلقائيًا مع GitHub؛ نفّذ أمر الرفع بعد التعديلات. يلزم مشروع Pages جديد لربط نشر تلقائي بـGitHub.
