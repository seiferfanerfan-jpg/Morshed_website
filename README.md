# morshed_Ai — مرشد

واجهة عربية أولية لمساعد مرشد، مبنية بـReact وTypeScript وVite.

## التشغيل المحلي

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج والتحقق من الأنواع:

```bash
npm run build
```

## حالة المساعد

واجهة المحادثة جاهزة بصريًا، لكن خدمة الذكاء الاصطناعي غير مربوطة بعد. لن تُرسل الرسائل إلى أي خادم ولن تظهر إجابات تجريبية. توجد نقطة فصل للخدمة في `src/services/assistant.ts`؛ أرسل مواصفات API وطريقة المصادقة عند جاهزيتها، وسنربطها بأمان. لا تضع مفاتيح سرية في كود المتصفح أو في ملفات Git.
